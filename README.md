# Jangles Game Hub

A collection of fun, educational kids games built with React, TypeScript, and TanStack Start. Deployed on Cloudflare.

## Games

- **Air Fante Collect** — Catch and collect items with Air Fante
- **Casey Can Count** — Number counting game with Casey
- **Count with Jaime** — Interactive counting practice
- **Draw with Casey** — Creative drawing game
- **Elefante** — Elefante adventure game
- **Find Foxy** — Spot Foxy hidden in the scene
- **Fly the Flag** — Learn world flags
- **Foxer** — Foxy-themed challenge game
- **Jangles Ball** — Ball game starring Jangles
- **Music Match** — Match sounds and instruments
- **Name That Country** — Geography guessing game
- **Sliding Puzzle** — Classic tile sliding puzzle
- **Spot the Difference** — Find what's different between two images
- **World Adventure** — Explore countries around the world

## Tech Stack

- **React 19** + **TypeScript**
- **TanStack Router** + **TanStack Start**
- **Tailwind CSS v4**
- **Radix UI** components
- **Framer Motion** animations
- **Vite** bundler
- **Cloudflare** deployment

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
